# Журнал фітнес-тренера

Офлайн-застосунок для телефона: тренер і клієнти ведуть записи тренувань на тренажерах залу APOLLO NEXT 023, бачать прогрес і схеми налаштувань тренажера.

## Команды

- Усі тести (з кореня): `node --test`
- Один файл: `node --test test/sync.test.js`
- Запуск: `python -m http.server 8765 --bind 127.0.0.1` з кореня -> http://127.0.0.1:8765/
- Збирання, npm, package.json немає. Лінтера немає.

## Где что

- `src/app.js` — точка входу, таблиця `routes` (хеш-маршрути, ролі), `homeFor`.
- `src/core/` — чисті модулі без DOM (`model`, `catalog`, `sync`, `chartdata`); сюди йдуть тести з `test/`.
- `src/store.js` — IndexedDB `trainer-log`; `src/ui/` — екрани й `dom.js`; `src/share.js` — файл через «Поділитися».
- `src/schemes/` — SVG-схеми тренажерів; нова схема = модуль + запис у `registry.js` + `schemeId` у `src/core/catalog.js`.
- `sw.js` — `CACHE_VERSION` і `PRECACHE`; `css/screens.css`, `css/schemes.css`, `app.css` — стилі.
- `gym/equipment.md`, `gym/adjustments.md`, `gym/my-photos/` — вихідні дані залу, з яких зроблено каталог і схеми.
- `brief.md` — слова автора про задачу.

## Подводные камни

- `node --test test/` падає (Node бере `test/` за файл) — тільки `node --test` або `node --test test/*.test.js`.
- `node --check` не ловить синтаксичні помилки ES-модулів (читає як CommonJS) — для цього `test/modules.test.js`.
- Новий файл у `src/`, `css/`, `icons/` -> допиши в `PRECACHE` у `sw.js` і підніми `CACHE_VERSION`, інакше падає `test/pwa.test.js`.
- `sw.js` віддає кеш першим: після правки без підняття `CACHE_VERSION` браузер показує старі файли. Перевіряй зі свіжим профілем або знімай service worker.
- Браузерні перевірки — лише headless Chrome через CDP зі свіжим профілем, не браузер користувача; UI тестами не покритий.
- Екран під час `render` ще не в DOM — розміри не міряти (графік на `viewBox`).
- Програма вже стоїть на телефонах з даними. Зміна стартового каталогу (`src/core/catalog.js`) -> підніми `CATALOG_VERSION` і перевір `upgradeEquipment` у `test/migration.test.js`: незмінене тренером замінюється, змінене тренером і тренажери з записами не зникають.
- Схеми: `src/schemes/upper.js` (верх тіла, прес, гантелі) і `legs.js` (ноги); `schemeId` задає каталог, без схеми — заглушка.
- Цифр регулювань не вигадувати: невідоме — `approx: true` або `unknown: true`. Жодного поля «нотатка». Без `alert/confirm` — є `confirmDialog` у `src/ui/dom.js`.

Архітектура — `docs/architecture.md`, рішення — `docs/adr/`, словник — `CONTEXT.md`.

## Як здесь работает Autopilot

Сборка ведётся навыком `/autopilot`. Требования, спецификация и таски — в `.autopilot/`.
Прогресс — `.autopilot/dashboard.html`. Требование из `manifest.md` может снять
только пользователь. Прерванную сборку продолжает «продолжи автопилот».

### Правка без автопилота

Мелкий баг или доводка после сборки — обычная сессия, без прогона.

Сначала прочитай:
1. `.autopilot/PROGRESS.md` — что не доделано, известные баги, о чём договорились с пользователем.
2. Что правили после последней сборки — первая строка таблицы в «История git».
3. Только если правка их касается: почему сделано так — `docs/adr/`; что значат слова — `CONTEXT.md`;
   что именно просили — `manifest.md` в папке сборки (указана в начале `PROGRESS.md`).

После правки:
- коммит — по правилам из «История git»;
- строка в «Правки без автопилота» в `PROGRESS.md`: дата — что — почему;
- починенный пункт из «Не доделано» или «Известные баги» — удали;
- договорились с пользователем о том, что следующая сборка не должна пересматривать, —
  строка в «Договорились», его словами.

### История git

Целиком не читай — бери срез под вопрос:

| Вопрос | Команда |
|---|---|
| что правили после последней сборки | `git log --oneline "$(git log -1 --format=%h --grep='^Autopilot: сборка сдана')"..HEAD -- . ':(exclude).autopilot'` |
| всё, что делали ради требования | `git log --oneline --grep="R02"` |
| история файла | `git log --oneline -10 -- <файл>` |
| когда появился или исчез код | `git log --oneline -S "<фрагмент>"` |
| почему строка такая | `git blame -L <с>,<по> <файл>`, затем `git show <sha>` |
| что внутри коммита | `git show --stat <sha>` |

Срез длиннее ~30 коммитов — отдай его субагенту и возьми выжимку в десять строк.

Коммит: заголовок — что (`fix: даты в одном формате`), тело — почему, трейлер
`--trailer "Requirements: R02"`, если правка касается требования из `manifest.md`.
Заголовок `Autopilot: сборка сдана` пишет только автопилот — по нему находят последнюю сборку.
